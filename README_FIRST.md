# José 2 anos — Asset Pack

Este pacote é o handoff visual oficial do projeto do convite/lista de presentes do aniversário de 2 anos do José.

## Regra principal para o Claude Code

**NÃO recriar, regenerar ou substituir os assets deste pacote.**
Sempre reutilizar os arquivos existentes pelos caminhos descritos em `docs/ASSET_USAGE.md` e `docs/asset-manifest.json`.

Exceções:
- fotos reais dos produtos são importadas no painel a partir do link/cadastro;
- mapa/localização é componente dinâmico;
- ícones funcionais devem vir de `lucide-react`;
- botões, cards, inputs, placas de madeira e estados visuais devem ser construídos em CSS, não como novas imagens.

## Onde copiar no projeto

Copie a pasta `public/assets` para a pasta `public/assets` do projeto Next.js.
Mantenha `design/reference` e `docs` na raiz do repositório para o Claude Code consultar.

## Referências principais

`design/reference/mockups/01-home.png` até `10-admin.png` definem a intenção visual e funcional das telas.
